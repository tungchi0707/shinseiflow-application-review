# ShinseiFlow

**WordPress向け申請審査・承認ワークフロー**

[English](README.md) | [日本語](README_ja.md) | [繁體中文](README_zh-Hant.md)

---

## 概要

ShinseiFlow は、WordPress 上で申請フォームの作成、申請受付、内容確認、審査結果の管理、通知メール送信、許可後のファイル提供までを一元管理できるオープンソースプラグインです。

単にフォームから内容を受け取るだけではなく、申請受付後の確認、許可、不許可、追加確認、修正・再申請、申請者による状況確認までを含む一連の申請業務を WordPress 内で管理できます。

## このような方に適しています

ShinseiFlow は、外部の申請管理 SaaS に依存せず、WordPress 上で申請受付から審査、通知、結果管理までを行いたい自治体、学校、団体、企業、地域プロジェクトなどに適しています。

## 主な利用例

- 自治体の各種申請受付
- 補助金・助成金申請
- 奨学金申請
- イベント・講習会・セミナーの参加申込
- ボランティア募集
- コンテスト・公募・作品応募
- 各種利用許可申請
- 社内申請・承認ワークフロー
- 許可者のみを対象としたファイル配布
- 人による確認や審査が必要な各種申請フォーム

## 単なるフォーム作成プラグインではありません

一般的なフォームプラグインは、主に入力内容を受け取ることを目的としています。

ShinseiFlow は、申請後の業務までを管理します。

- WordPress 管理画面で申請内容を確認
- 許可・不許可の審査結果を管理
- 必要に応じて追加確認を依頼
- 審査状況に応じた通知メールを送信
- 申請者が現在の状態や申請内容を確認
- 修正・再申請に対応
- 許可後にダウンロードファイルを提供
- 申請履歴やステータス変更を記録

## インストール

1. プラグインフォルダを `/wp-content/plugins/` にアップロードするか、WordPress 管理画面からインストールします。
2. **ShinseiFlow – Application Review & Approval Workflow** を有効化します。
3. 申請フォーム、通知メール、セキュリティ設定、多言語設定、フロントエンドページを設定します。
4. 必要なショートコードを固定ページに配置します。

## ショートコード

- `[tcarm_form]` — 申請フォーム
- `[tcarm_status]` — 申請状況確認
- `[tcarm_view]` — 申請内容表示
- `[tcarm_edit]` — 修正・再申請フォーム

## 開発方針

ShinseiFlow は、長期的な保守性、使いやすさ、プライバシー、セキュリティ、WordPress との互換性を重視して設計しています。

AI は開発支援ツールとして利用していますが、機能設計、構成、テスト、セキュリティ確認、操作性の判断、リリース品質は人が確認しています。

単にコードを生成することではなく、安定して運用でき、継続的に保守できる実用的な WordPress プラグインを目指しています。
